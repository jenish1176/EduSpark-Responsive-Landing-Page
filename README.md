# EduSpark — Responsive Product Landing Page

## Project Overview
EduSpark is a fictional online learning platform that helps college students and beginners learn programming, web development, UI/UX design, and other technical skills.

## Objective
To design a visually appealing, user-friendly, and responsive landing page using Figma, Auto Layout, reusable components, and consistent design styles.

## Target Audience
- College students
- Beginners learning technical skills
- People interested in online courses and career development

## Main Sections
1. Header and navigation
2. Hero section with call-to-action buttons
3. Platform statistics
4. Features section
5. Popular courses
6. Call-to-action section
7. Footer

## Design System
- Primary color: #6C4CF1
- Secondary color: #4F7DF3
- Background: #F7F8FC
- Text color: #17172E
- Typography: Inter or Poppins

## Reusable Components
- Primary and secondary buttons
- Feature cards
- Course cards

This project demonstrates landing-page design, visual hierarchy, spacing consistency, reusable components, Auto Layout, and responsive design principles.
